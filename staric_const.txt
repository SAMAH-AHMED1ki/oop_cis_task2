const وظيفتها إنها تمسك this عشان تعرف تمنع التعديل على مين. الـ static function معندهاش this أصلاً لأنها مش مرتبطة بـ object معين. فـ const مالهاش حاجة تشتغل عليها، فالكومبايلر بيرفض الجمع بينهم.

السؤال 2: ليه استخدام this للوصول لـ static member مالوش معنى؟

this بيشاور على object معين. لكن المتغير الـ static مش موجود جوه أي object، هو مكان واحد بس في الذاكرة مشترك بين الكل. فاستخدام this هنا مش بيضيف أي فايدة هتاخدي نفس القيمة سواء استخدمتيه أو لأ، لأن employees_count مالهاش نسخة خاصة جوه كل object أصلاً.
